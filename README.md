# Agent-Skills-Manager  
*Build, Manage & Share AI Agent Skills with Ease*  

---

## ✨ Features
- 📝 **Create & manage AI agent skills** (powered by Markdown)
- 🔐 **Secure user authentication** (bcrypt password hashing + httpOnly cookies)
- 📸 **Public skills gallery** with Next.js Incremental Static Regeneration (ISR)
- 💾 **PostgreSQL database** with Prisma 7 ORM
- 🎨 **Beautiful UI** powered by Tailwind CSS + DaisyUI
- 🚀 **Deployed on Vercel** for global, fast access

---

## 🛠️ Tech Stack
| Layer | Tools |
|-------|-------|
| Framework | Next.js 16 + React 19 |
| Styling | Tailwind CSS + DaisyUI |
| Database | PostgreSQL + Prisma 7 |
| Auth | bcrypt + httpOnly cookies |
| Deployment | Vercel |
